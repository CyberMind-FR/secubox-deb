Le Coffre

La carte du Hall qui garde la clé de signature du dépôt, les secrets des services, les graines TOTP et les clés GPG. Tant qu'un humain authentifié ne l'a pas ouverte, rien de ce qu'elle garde en niveau 1 n'est lisible, pas même par root. Les trois états sont présentés ci-dessous. Les champs sont manipulables ; aucune donnée ne quitte la page.

    État 3

    Recouvrement par le maillage

    Phrase oubliée, clé d'appareil perdue, plus de code de secours. Deux nœuds MirrorNet sur trois rendent leur part, chacun après un TOTP validé chez lui. Le TOTP autorise le nœud à rendre sa part ; la clé elle-même n'en dérive pas.

    Conception : docs/design/coffre/README.md. Niveau 1 = protégé par la clé maîtresse, absente du disque. Niveau 0 = systemd-creds (clé d'hôte) : illisible dans une copie du disque ou une sauvegarde, lisible par root sur la box en marche.
