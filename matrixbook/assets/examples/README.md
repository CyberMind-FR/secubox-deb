## Comment utiliser un chemin de fer

Le chemin de fer est le plan de la publication, double page par double page.
C'est le premier livrable de tout projet MatrixBook, avant même l'ouverture du
logiciel de mise en page. Sa construction est décrite dans la section
« Narration visuelle » de [MATRIXBOOK_DESIGN.md](../../docs/MATRIXBOOK_DESIGN.md#2-narration-visuelle).

Chaque ligne du chemin de fer indique :

1. les numéros de pages de la double page (verso gauche pair, recto droit impair) ;
2. le rôle narratif (ouverture, développement, respiration, clôture) ;
3. le type de composition retenu parmi ceux de
   [BOOK_LAYOUT.md](../../docs/BOOK_LAYOUT.md#8-composition-des-doubles-pages) ;
4. le contenu texte et le contenu image prévus ;
5. le ratio texte/image visé.

Un chemin de fer se relit à voix haute : si l'enchaînement des rôles ne
« raconte » rien, la maquette ne racontera rien non plus.
