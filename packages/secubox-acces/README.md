# secubox-acces

Transitional package — device admission moved to secubox-sbxid.

L'admission des appareils (demande, défi signé, session, porte d'accès) fait désormais partie du SBX Identity Manager (secubox-sbxid), aux mêmes chemins. Ce paquet peut être retiré sans effet.

Paquet Debian : version `1.7.0-1~bookworm1`, architecture `all`.

## Dépendances SecuBox

`secubox-sbxid`.
