Demander de l'assistance (ciblée)

Requête ciblée : tu choisis le centre qui aide (par DID).

Marketplace d'entraide (mesh) — clique un onglet : Proposer de l'aide, Demander de l'aide au mesh, voir les Matches, ou Partager un lien d'invitation.

🙋 Proposer de l'aide

Annonce ta disponibilité : les box du mesh qui cherchent de l'aide sur ces tags te verront (onglet Matches).

🆘 Demander de l'aide (ouverte)

Requête ouverte : publiée au mesh sans cibler personne — un offreur compatible se propose (voir Matches). Pour cibler un centre précis par DID, utilise le formulaire « Demander de l'assistance (ciblée) » en haut.

🔗 Matches

Paires offre↔demande compatibles rapprochées par le mesh. Accepte ta part ; quand les deux côtés ont accepté, la session s'ouvre.

📤 Partager un lien d'invitation

Génère un lien à usage unique à partager hors-bande (mail, chat) pour inviter quelqu'un — même hors mesh — à une session d'assistance.

📥 Rejoindre via un lien

Colle un lien d'invitation reçu pour rejoindre une session. L'escalade automatique (tunnel WireGuard éphémère) arrive dans une prochaine version.

L'escalade depuis un lien reçu est un suivi documenté — non câblée dans cette version.
