About this module

SecuBox runs Authelia 4.39+ in an LXC at 10.100.0.20. This page surfaces operator metrics — service state, configured users, cookie scopes, access policies. The actual login portal lives on its own public vhost sso.gk2.secubox.in; every sibling app (zigbee, lyrion, nextcloud, …) redirects unauthenticated requests there.

Click Open SSO Portal → to reach the login UI. Backups of /etc/secubox/secrets/authelia-* survive package upgrades.
