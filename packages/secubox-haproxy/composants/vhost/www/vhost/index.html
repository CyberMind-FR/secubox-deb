WAF et exposition

Tout le trafic public passe par le WAF (sbxwaf). Cette page ne crée aucun contournement : un contournement se déclare dans haproxy.toml (waf_bypass par vhost). La case « Anti-robots » demande au WAF de refuser les robots d’indexation (403) sur le vhost.

Ce que cette page ne montre pas

L’API ne fournit ni les dossiers de configuration, ni la version du module, ni l’historique des rechargements : rien n’est affiché à leur place. Les journaux par vhost, le test de configuration et la migration OpenWrt existent côté API mais n’ont jamais eu de bouton ici.
