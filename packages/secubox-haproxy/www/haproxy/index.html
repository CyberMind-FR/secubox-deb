Le nom d’hôte de la box est celui de cette page. Un vhost « contourne le WAF » seulement s’il le déclare dans la configuration.

Hôtes virtuels

DomaineBackendTLSWAFActions

L’API enregistre la demande et resynchronise les routes du WAF ; la définition des vhosts reste celle de la configuration HAProxy (haproxy.toml). Régénérez puis rechargez ensuite depuis l’onglet Actions.

Backends

NomModeÉquilibrageServeursActions

Même remarque que pour les vhosts : l’API journalise la demande sans modifier haproxy.toml. La modification d’un backend existant et la gestion serveur par serveur n’ont pas de route côté API.

Intégration WAF

Ouvrir le tableau WAF

Avec le WAF actif, le trafic HTTP traverse sbxwaf avant d’atteindre les backends : client, HAProxy, WAF, backend. L’API ne persiste pas l’état du WAF dans haproxy.toml : l’état affiché reste celui de la configuration.
