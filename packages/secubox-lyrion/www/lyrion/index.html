Hardware Squeezebox / Squeezelite players connect on TCP/UDP 3483 (DNAT lan0 → 10.100.0.100 in nftables). 0 players usually means the device is on a different L2 segment and broadcast discovery isn't crossing — set the LMS IP manually on the device or put the WiFi AP in bridge mode.

Actions

"Rescan library" triggers an LMS database refresh — useful after adding new files under /data/music/. May take minutes on large libraries.
