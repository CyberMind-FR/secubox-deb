# secubox-mail-lxc

Transitional package — mail LXC functionality moved to secubox-mail.

The single consolidated mail LXC is now installed and driven by secubox-mail (>= 2.2). This package ships no files. Safe to apt-get autoremove after upgrade.

Paquet Debian : version `2.2.1-1~bookworm1`, architecture `all`.

## Exécution

Socket Unix : `/run/secubox/mail-lxc.sock`.

## Dépendances SecuBox

`secubox-mail`.
