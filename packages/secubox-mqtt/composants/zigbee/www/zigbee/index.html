    À propos

    SecuBox fait tourner zigbee2mqtt dans un conteneur LXC avec un coordinateur SONOFF Dongle-E. L’appairage, la carte du réseau, les mises à jour OTA et les groupes se gèrent dans le gestionnaire Zigbee dédié (accès filtré) : bouton « Ouvrir le gestionnaire Zigbee ».

    Cette page montre la santé côté SecuBox (composants, pont MQTT, accès) pour vérifier que la pile tourne avant d’ouvrir le gestionnaire.
