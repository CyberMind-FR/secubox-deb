Serveur de boot TFTP + HTTP —

Ce serveur ne fait que servir : aucun overlay ni flash n’est posé sur lui.

Cartes netbooter une box : par le réseau ou par clé USB, puis l’eMMC

Par le réseau : le U-Boot d’usine charge le live par TFTP, le live récupère son système par HTTP (port 8099, réseau local seulement), puis sbx-netflash écrit l’image choisie après en avoir vérifié la signature. Par la clé USB finale : le système lui-même tourne sur la clé pour les tests, et l’autoflash l’écrit sur l’eMMC.

Préparer un flash la box rejoint seule ce maître

Valable 24 h, pour un seul flash. Sans préparation, une box qui porte déjà ce nom n’est pas remplacée. Le mot de passe n’est jamais gardé en clair (empreinte argon2).
