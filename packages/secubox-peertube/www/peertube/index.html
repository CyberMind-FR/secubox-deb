Importer une vidéo ou une liste de lecture POST /import, /playlist/import

Télécharge une vidéo (YouTube, Vimeo, lien direct…) directement dans cette instance, via yt-dlp. Une URL de liste de lecture (list=, /playlist, /sets/…) est développée et importée vidéo par vidéo : une vidéo en échec n’arrête pas les autres, et relancer la même URL saute ce qui est déjà fait.

Le titre sert de préfixe pour chaque vidéo d’une liste de lecture. Sans titre, PeerTube en déduit un.
