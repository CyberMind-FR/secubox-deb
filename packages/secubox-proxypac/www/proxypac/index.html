Firefox — réglages recommandés (about:config) :
• network.proxy.socks_remote_dns = true — force la résolution DNS à travers le proxy PAC/SOCKS (indispensable pour les hôtes .onion et pour éviter les fuites DNS locales).
• network.dns.blockDotOnion = false — autorise Firefox à transmettre les hôtes .onion au résolveur proxy au lieu de les bloquer avant même l'appel PAC.
• network.trr.mode = 0 — désactive le DoH natif Firefox (Trusted Recursive Resolver) pour que la résolution passe bien par socks_remote_dns et non par un résolveur DoH tiers en dur.
