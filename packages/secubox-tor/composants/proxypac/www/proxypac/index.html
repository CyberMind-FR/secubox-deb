Mode transparent

—

Transparent activé : redirection nft implicite, aucune configuration côté client. Désactivé : le client doit utiliser explicitement le PAC ou le SOCKS. « Appliquer WPAD » réécrit la publication WPAD (DHCP 252 ou DNS) selon le rôle.

Firefox, réglages recommandés (about:config) :

  • network.proxy.socks_remote_dns = true — la résolution DNS passe par le proxy (indispensable pour les hôtes .onion, évite les fuites DNS locales).
  • network.dns.blockDotOnion = false — laisse Firefox transmettre les hôtes .onion au résolveur proxy au lieu de les bloquer avant l’appel PAC.
  • network.trr.mode = 0 — désactive le DoH natif pour que la résolution suive socks_remote_dns.
