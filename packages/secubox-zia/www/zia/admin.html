🧠 Moteur

Vide = répondeur heuristique (honnête, sans génération). Renseigne l'URL d'un llama-server local (ex. http://127.0.0.1:8091) pour la formulation. Les objets viennent toujours du bus — le modèle n'invente rien.

🔑 Accès & bus

Le rôle par défaut borne ce qui est visible tant que l'auth du Hall n'est pas branchée. Le cache du bus lisse les appels aux adapters (MetaNews, Billets, PeerTube, registre).

🛰️ Niveau 3 · Remote

Dernier recours, désactivé par défaut. Tenté seulement si le rôle l'autorise ET qu'un endpoint est réglé : contexte minimal, secrets rédigés, budget horaire + timeout + coupe-circuit, repli local systématique. Ce n'est jamais une dépendance.
