About this module

SecuBox manages a zigbee2mqtt instance running in an LXC at 10.100.0.111 with a SONOFF Dongle-E coordinator. Pairing, network maps, OTA updates, and group bindings are handled by the Zigbee Manager — open it via the button above (Authelia SSO-gated).

This module surfaces the SecuBox-side health (component state, MQTT bridge status, access points) so operators can confirm the stack is up before opening the manager.
