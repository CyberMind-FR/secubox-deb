About this module

SecuBox runs zigbee2mqtt in an LXC at 10.100.0.111 with a SONOFF Dongle-E coordinator. Pairing, network maps, OTA updates, and group bindings are handled by the dedicated Zigbee Manager vhost (Authelia SSO-gated) — click Open Zigbee Manager →.

This page surfaces the SecuBox-side health (component state, MQTT bridge, access endpoints) so operators can confirm the stack is up before opening the manager.
