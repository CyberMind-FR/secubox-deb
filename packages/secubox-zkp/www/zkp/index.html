Comment ça marche

            
Une preuve à divulgation nulle permet de démontrer qu’on connaît une valeur sans rien révéler d’elle. SecuBox utilise un chemin hamiltonien : un trajet qui visite chaque nœud d’un graphe une seule fois, sans jamais le dévoiler.

            
  1. Générer une clé : un graphe aléatoire contenant un chemin hamiltonien connu de vous seul.
  2. Générer la preuve : une preuve de connaissance de ce chemin, sans le révéler.
  3. Vérifier : n’importe qui peut contrôler la preuve à partir du graphe public.

            
Usages : authentification du maillage, validation de configuration, échange sûr de paramètres.
