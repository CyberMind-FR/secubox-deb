# Grammaire visuelle

Un signe par concept, **le même partout**. Une icône qui change de sens d'une
page à l'autre coûte plus qu'elle ne rapporte.

## Règle de fond

Chaque icône est doublée d'un **mot**. Jamais d'icône seule pour porter une
information : l'icône accélère la reconnaissance de ce qu'on sait déjà, elle
n'enseigne rien à qui ne le sait pas encore.

## Le répertoire

### Personnes et rôles

| Concept | Signe | Note |
|---|---|---|
| Utilisateur | silhouette simple | jamais genrée |
| Administrateur | silhouette + clé | la clé, pas la couronne |

### Communication

| Concept | Signe |
|---|---|
| Courriel | enveloppe |
| Discussion | bulle de dialogue |
| Forum | bulles superposées |
| BBS | écran à curseur |

### Fichiers

| Concept | Signe |
|---|---|
| Fichier | feuille |
| Dossier | chemise |
| Nextcloud | nuage |
| Sauvegarde | flèche vers coffre |
| Restauration | flèche depuis coffre |

### Média

| Concept | Signe |
|---|---|
| PeerTube | écran + lecture |
| Mastodon | bulle + réseau |
| Audio | onde |
| Direct | point plein |

### Réseau

| Concept | Signe |
|---|---|
| Réseau | nœuds reliés |
| Wi-Fi | arcs |
| Serveur | boîtier à rainures |
| VPN | tunnel |
| Tor | oignon en coupe |
| DNS | panneau indicateur |

### Sécurité

| Concept | Signe |
|---|---|
| Sécurité | bouclier |
| Verrouillé | cadenas fermé |
| Chiffrement | cadenas + clé |
| Pare-feu | mur |

### Signalements

| Concept | Signe | Emploi |
|---|---|---|
| Information | i cerclé | contexte utile |
| Conseil | ampoule | fait gagner du temps |
| Avertissement | triangle | peut mal tourner |
| Danger | octogone | **irréversible** |

**Danger** est réservé à l'irréversible : effacement, remplacement, perte
définitive. L'employer pour un simple avertissement le vide de son sens — et le
jour où il compte vraiment, personne ne s'arrête.

### Technique

| Concept | Signe |
|---|---|
| Terminal | invite `>` |
| Navigateur | fenêtre à onglet |
| API | prise / connecteur |

## Réalisation

Icônes **libres**, dessinées pour SecuBox ou issues d'un jeu libre. Pas de
dépendance à un jeu propriétaire sans nécessité : la documentation doit pouvoir
être reprise, traduite et réimprimée sans demander la permission à personne.

Trait uniforme, grille commune, lisible à 16 px comme à 512 px.
