# Vocabulaire

Un terme, un sens, **le même partout**. Cette page tranche ; elle ne discute pas.

## Ce que l'utilisateur voit

| Terme retenu | À ne pas employer | Ce que c'est |
|---|---|---|
| **SecuBox** | la box, le boîtier | l'appareil et son système |
| **application** | app, service, module | ce que l'utilisateur ouvre et utilise |
| **module** | paquet, package | l'unité livrée et installée — vocabulaire d'administration |
| **compte** | utilisateur, user | l'identité de connexion |
| **tableau de bord** | dashboard | la page d'accueil après connexion |
| **courriel** | mail, email | un message électronique |
| **webmail** | client mail | le courriel dans le navigateur |
| **fichier** | document, doc | un fichier |
| **partager** | share | rendre accessible à quelqu'un d'autre |
| **téléverser** | uploader | envoyer un fichier vers la SecuBox |
| **télécharger** | downloader | récupérer un fichier depuis la SecuBox |

## Ce qui distingue « application » et « module »

C'est la distinction la plus utile de cette page.

- **Application** — ce que l'utilisateur ouvre. « Ouvrez l'application Webmail. »
- **Module** — l'unité que l'administrateur installe, met à jour, surveille.
  « Le module `secubox-mail` fournit le webmail. »

Un module peut fournir plusieurs applications. Une application peut reposer sur
plusieurs modules. Employer l'un pour l'autre brouille exactement la frontière
entre les deux publics.

| Terme | Formulation retenue |
|---|---|

## Les rôles

| Terme | Qui c'est |
|---|---|
| **utilisateur** | se sert de la SecuBox |
| **administrateur** | la configure et en assume les conséquences |
| **sysop** | administrateur du BBS — terme propre au module, conservé |

## Les niveaux

`debutant` · `intermediaire` · `avance` · `admin`

Ce sont les valeurs du champ `level` des fiches sources. Sans accent ni
majuscule dans le code ; en toutes lettres à l'affichage.

## Ce qui ne se dit pas

- « Simplement », « il suffit de », « évidemment ».
- « Erreur » sans dire laquelle.
- « Bientôt disponible » : soit ça existe et on le documente, soit non et on
  n'en parle pas.
- Le nom de domaine d'une board réelle dans une fiche générale.
