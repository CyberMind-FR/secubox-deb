# Modèle — script vidéo

Une vidéo par tutoriel. **1 à 3 minutes.** Au-delà, personne ne la finit.

Le script se dérive de la fiche source : mêmes étapes, mêmes résultats
attendus. S'il diverge, c'est la fiche qui fait foi.
