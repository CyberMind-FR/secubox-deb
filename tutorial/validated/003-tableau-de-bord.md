# Comprendre le tableau de bord

## Objectif
Savoir se repérer après la connexion.

## Étapes
1. Observer les applications auxquelles le compte a accès.
2. Ouvrir une application.
3. Revenir au tableau de bord.

## À retenir
- Le tableau de bord liste les applications accessibles au compte.
- Une application absente peut ne pas être installée ou ne pas être autorisée pour ce compte.
- Le tableau de bord est le point de retour pour naviguer dans SecuBox.
