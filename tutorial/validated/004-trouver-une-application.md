# Trouver une application

Partez de ce que vous voulez faire, pas du nom du produit.

| Besoin | Application / module |
|---|---|
| Courriel | Webmail · `secubox-mail` |
| Fichiers | Nextcloud · `secubox-nextcloud` |
| Photos | PhotoPrism · `secubox-photoprism` |
| Forum | BBS · `secubox-bbs` |
| Discussion directe | Matrix · `secubox-matrix` |
| Réseau social fédéré | Mastodon · `secubox-mastodon` |
| Vidéo | PeerTube · `secubox-peertube` |
| Musique | Lyrion · `secubox-lyrion` |
| Médiathèque | Jellyfin · `secubox-jellyfin` |
| Podcast | Podcaster · `secubox-podcaster` |
| Billet | Billets · `secubox-billets` |

La liste technique complète reste dans `tutorial/catalog/modules.md`.
